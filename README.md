# Formulário

Uma página com um formulário para preenchimento e envio de informações pelo usuário.

## Funcionalidades

- Campos para preenchimento de dados
- Diferentes tipos de campos
- Validação das informações
- Botão para envio do formulário
- Interface organizada e interativa

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
